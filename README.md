<summary><b>🐍 Snake Classifier (SerpentClassifier)</b></summary>
<br/>

Binary image classification system distinguishing venomous from non-venomous snakes across 135 species using two comparative approaches: deep learning transfer learning and classical machine learning.

| Aspect | Details |
|---|---|
| **Stack** | Python, TensorFlow/Keras (MobileNetV2), scikit-learn (SVM), OpenCV |
| **Scale** | ~27,000 images across 135 snake species |
| **Performance** | Comparative evaluation of MobileNetV2 transfer learning vs. SVM with HOG/HSV/LBP + PCA features |
| **Security** | Local dataset processing, no external data exposure |
| **Impact** | Demonstrates practical tradeoffs between deep learning and classical ML pipelines for real-world image classification |
| **Repository** | *Private / Academic* |

</details>
